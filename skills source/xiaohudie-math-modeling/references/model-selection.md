# 题型判断与模型选型指南

> xiaohudie 独立整理的数模选型方法论（社区实践参考出处见 SOURCES.md）。选型前先通读本文，再结合题目数据特征定方案。

## 五大题型识别

| 题型 | 核心问法 | 典型场景 |
|---|---|---|
| 优化类 | 求最大/最小，资源怎么分配 | 路径规划、调度、选址、装箱、投资组合 |
| 预测类 | 预测未来数值或趋势 | 销量/人口/价格预测、时序分析 |
| 评价类 | 对多方案综合排序或打分 | 城市评级、供应商选择、方案比选 |
| 分类/聚类类 | 判断类别归属或自动分群 | 风险识别、客户分群、图像识别 |
| 机理/动力学类 | 描述系统随时间的演化 | 传染病传播、生态系统、物理仿真 |

拿到题先问：输出是一个数（优化）、一条序列（预测）、一个排名（评价）、一个类别标签（分类）还是一组微分方程（机理）？混合题型按主问题定主模型，子问题按实际需求叠加。

## 选型决策树

```text
要预测未来数值？
  数据量 < 15 → GM(1,1) 灰色预测
  纯时序、无外部变量 → ARIMA / 指数平滑
  有多个影响因素 → 线性回归 / 岭回归 / 随机森林 / XGBoost
  非线性很强 → XGBoost / LSTM（样本 1000+）
  需要不确定性区间 → Bootstrap / MCMC

要评价/排序/选方案？
  需要体现专家经验 → AHP（主观赋权）
  完全客观数据驱动 → 熵权法（客观赋权）
  方案间距离排序 → TOPSIS / AHP+TOPSIS
  指标有模糊语言（好/中/差）→ 模糊综合评价
  评价投入产出效率 → DEA
  数据少、信息不全 → 灰色关联分析
  指标多且高度相关 → PCA + TOPSIS

要优化（求最大/最小）？
  目标和约束都线性 → 线性规划（scipy.linprog）
  含整数/0-1 变量 → 整数规划（milp / pulp）
  非线性目标或约束 → 非线性规划（scipy.minimize）/ 遗传算法 / 模拟退火
  多目标冲突 → NSGA-II / 加权和法（先归一化）/ ε-约束法
  序贯决策 → 动态规划

要分类/分群？
  有标签（监督）→ 随机森林 / SVM / Logistic 回归
  无标签（无监督）→ K-means / 层次聚类 / DBSCAN
  文本/情感 → TF-IDF + LDA / 情感词典

要建机理模型？
  连续时间系统 → 常微分方程 ODE（SIR、Lotka-Volterra、Logistic）
  偏微分/空间扩散 → PDE / 有限差分
  离散时间系统 → 差分方程 / 马尔可夫链
  不确定性/风险 → 蒙特卡洛模拟
  空间离散演化 → 元胞自动机
```

## 高分组合表（评委偏好显式化）

| 问题类型 | 推荐组合 | 说明 |
|---|---|---|
| 综合评价 | AHP + TOPSIS 或 AHP+熵权+TOPSIS | AHP 定权、TOPSIS 排序；主客观结合更有说服力 |
| 预测+不确定性 | XGBoost/随机森林 + Bootstrap 置信区间 | 预测 + 置信带 |
| 风险评估 | Logistic 回归 + 蒙特卡洛模拟 | 概率 + 模拟 |
| 时空预测 | ARIMA/LSTM + 空间聚类 | 时间 + 空间维度 |
| 投资/资源优化 | 预测模型 + 动态规划/遗传算法 | 预测驱动的优化 |
| 状态建模 | 马尔可夫链/HMM + 随机森林验证 | 转移规律 + 校验 |
| 文本分析（美赛 C） | TF-IDF + LDA 主题模型 + 情感分析 | 特征 + 主题 + 情感 |
| 效应分析 | DID/回归 + SHAP 值 | 因果 + 解释 |

## 美赛题型规律（历年 MCM/ICM）

- **A 题（连续型）**：微分方程、物理/工程建模、优化，数学推导要求高。
- **B 题（离散型）**：图论、调度、组合优化、排队论，算法实现要求高。
- **C 题（数据洞察型）**：数据分析、机器学习、时序预测、可视化，数据处理能力要求高。
- **D/E/F 题（ICM）**：运筹学、可持续性、政策分析，跨学科与文字论证要求高。

## 分领域防错要点

### 评价类
- AHP：判断矩阵 ≤ 9×9，否则拆多级层次；CR < 0.1 才通过，不通过必须调矩阵；权重归一化后求和=1；得分 = 权重向量 × 方案矩阵。
- 熵权法：某指标所有方案取值相同时熵权为 0，是正常结果不是 bug；熵权忽略业务重要性，必要时 AHP+熵权组合；正负向标准化要统一（正向 (x−min)/(max−min)，负向 (max−x)/(max−min)）。
- TOPSIS：≥2 个方案才可用；必须先标准化再算距离；贴近度 C = D⁻/(D⁺+D⁻) 越接近 1 越优，不是百分制得分；指标高度相关时先用 PCA 降维。
- 模糊综合评价：隶属度函数按问题语义选（三角形/梯形/高斯）；合成算子用 M(·,+) 加权平均型，不用 M(∧,∨)；指标过多时用二级模糊综合评价。

### 预测类
- 时序必须按时间顺序划分训练/验证集，禁止随机打乱；scaler 只在训练集 fit。
- ARIMA：差分阶数 d 由 ADF 检验定，p、q 由 ACF/PACF 或 AIC/BIC 定。
- GM(1,1) 只适合单调递增/近似指数序列，震荡与递减序列失效；仅适合短期预测。
- 预测结果检查物理边界（人口非负、概率 ≤1、库存 ≤ 上限）；外推超出训练范围必须声明风险。
- 回归诊断：VIF > 10 处理共线性；残差应正态、方差齐、无自相关。

### 优化类
- 先保证可行解再优化目标；`scipy.optimize.minimize` 只做最小化，最大化取负目标并在结果还原。
- scipy 不等式约束方向是 `fun(x) >= 0`，容量上限 x ≤ C 写成 C − x ≥ 0。
- **工程铁律（极易扣分）**：每个优化变量必须有物理上下界（如绳长受模型高度限制 L ≤ 500mm）。若无约束解违反物理限制，在结果中明确写出"无约束解为 XX，违反物理限制，引入约束后最优解为 YY"——评委看到这种工程思维会给高分。
- 整数变量取整后必须重新验证可行性，不可行用修复启发式，不要四舍五入了事。
- 启发式（GA/SA/PSO）：固定随机种子、≥5 次独立运行、报告均值±标准差，禁止直接宣称全局最优。
- 多目标必须先各目标独立无量纲化再加权或做 Pareto 分析，报告各目标分量贡献。

### 机理/仿真类
- 状态变量要有物理含义与量纲；初始条件、边界条件必须明确。
- 刚性系统用 `solve_ivp(method='Radau'/'BDF')`，不要默认 RK45。
- 检查守恒量（SIR 中 S+I+R=N 常数）；步长减半结果变化 <1% 才算收敛。
- 蒙特卡洛采样 ≥10,000 次并报告置信区间；元胞自动机必须说明边界条件选择理由；马尔可夫转移矩阵每行和为 1。

### 图论类
- 明确有向/无向、权重、容量、连通性；负权边禁用 Dijkstra（用 Bellman-Ford）。
- 节点 >1000 时 Floyd 的 O(V³) 不可接受，改多次 Dijkstra；最大流要验证流量守恒。
- TSP/VRP 禁止子回路；无向图最大流转化为两条反向有向边。

### 统计与机器学习
- 过拟合防护：训练/验证/测试三分，测试集绝不参与调参。
- 类别不平衡用 F1/AUC-ROC，不用 Accuracy；时序交叉验证用 TimeSeriesSplit。
- 特征重要性 SHAP 比 feature_importances_ 可靠（后者对相关特征有偏）。
- 统计检验速查：两组均值 t 检验（正态+方差齐）；多组 ANOVA；非参数 Mann-Whitney U；相关 Pearson/Spearman；独立性卡方（期望频数 ≥5）；平稳性 ADF；正态性 Shapiro-Wilk。

## EDA 分流（避免模板化扣分）

先判断题目参数是"数据集"还是"物理常量"：
- **物理/力学机理题**（参数为确定常量如 H=200mm）：**不写描述性统计**，不画直方图/箱线图、不提异常值清洗——评委会认为在套数据分析模板。EDA 聚焦：几何关系推导、参数物理一致性、量纲检查。
- **数据驱动题**（真有数据集）：EDA 覆盖数据结构、缺失值报告（缺失率+填充策略）、异常值检测（IQR/Z-score）、分布可视化、相关性热力图、分组对比。

## 可视化方案速查

| 数据类型 | 推荐图表 |
|---|---|
| 趋势/时序 | 折线图 + 置信带（fill_between） |
| 分布比较 | 箱线图/小提琴图 |
| 相关性 | 散点图+回归线+r 值；多变量用热力图 |
| 分类对比 | 水平条形图（不用饼图、3D 柱状图） |
| 参数敏感性 | 热力图/等高线/带阴影折线 |
| 后验分布 | 密度图/直方图+KDE |
| 模型对比 | 分组柱状图或指标矩阵 |

必须包含的核心图：预测类→预测结果图（含置信区间）；分类类→混淆矩阵；相关性分析→热力图；敏感性分析→参数敏感性曲线；特征重要性→至少 1 张。
