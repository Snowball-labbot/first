## 本文件负责

本文件是 P1 输入材料数据属性判断、P3 原始数据版本、数据血缘、质量、划分、泄漏、公开数据和文献治理的唯一规范。
它确保论文中的数据事实和外部结论具有可审计来源。

## 本文件不负责

本文件不选择模型、不定义题型验证方法、不决定论文叙事，也不把公开页面内容自动视为可信。
下载或读取成功只是可访问性证据，不等于来源权威、许可合规或字段语义正确。

## 原始数据与版本

对每个原始数据源建立只读副本或不可变快照，登记：

- `artifact_id`、规范路径、SHA-256 和字节数；
- 提供者、原始 URL 或用户说明；
- 获取时间、发布日期和版本号；
- 许可、使用限制和引用要求；
- 文件格式、编码、工作表或表名；
- 字段名、类型、单位、时区和类别字典；
- 覆盖的时间、空间、主体和样本范围；
- 缺失值表示、哨兵值和质量标志；
- 是否含身份、敏感或受限信息。

原始副本不在原位清洗。
任何人工更正、格式转换或编码修复都产生新的 artifact 和 transform 记录。

同名文件不代表同一版本。
每次上游数据变化都计算新哈希，并使依赖 execution、result、claim、figure 和 manuscript 绑定陈旧。

数据修订记录说明旧值、新值、来源、理由、影响行和受影响结论。
不能悄悄修正异常以改善模型表现。

## 数据血缘

数据血缘连接：原始源 → 解析 → 清洗 → 派生 → 筛选 → 划分 → 模型输入 → 结果。
每个 transform 至少登记：

- 输入 artifact ID 列表；
- 代码和配置 artifact ID；
- execution ID；
- 输出 artifact ID；
- 行列数、键唯一性和 schema；
- 删除、新增和修改的记录统计；
- 过滤条件、连接键和聚合单位；
- 时间、空间和主体范围变化；
- 质量断言及其结果。

连接操作必须报告未匹配键、重复键和多对多膨胀。
聚合必须声明分母和分析单位。
派生变量必须给出公式、单位和缺失传播规则。

筛选依据若使用结果变量或未来信息，必须被识别为潜在泄漏。
只在图中显示的数据也需要血缘，不能绕过 Registry。

## 划分和泄漏控制

先确定独立性和信息可用性，再划分数据。
会学习分布的预处理必须只在训练部分拟合，包括缩放、插补、降维、特征选择、目标编码、词典学习和阈值选择。

按结构选择隔离单位：

- 时间：训练信息严格早于验证与测试预测时点；
- 空间：使用空间块、留区或与目标外推一致的设计；
- 主体：同一主体不跨外层集合；
- 群组/批次：按真实部署中新群组是否出现决定；
- 重复测量：实验单位而非行数决定独立样本；
- 图或网络：处理共享节点、边和邻域信息泄漏；
- 仿真：校准情景和验证情景分离。

建立 leakage audit，逐项检查：

1. 未来或测试标签进入特征；
2. 全数据拟合预处理；
3. 重复或近重复样本跨集合；
4. 同主体、地点、设备或批次跨集合；
5. 外部数据发布时间晚于预测时点；
6. 目标定义使用后验信息；
7. 手工特征根据测试错误反复修改；
8. 代理变量直接编码答案。

已知泄漏是提交红线。
不能用模型性能下降作为不修复泄漏的理由。

## 数据质量与缺失

先区分：

- 数据错误：解析错、单位错、录入错、重复、无效编码；
- 真实极端：稀有但可能的现象；
- 异常机制：传感器故障、制度变化或不同总体；
- 缺失：随机、条件随机、非随机、结构性不适用；
- 截断、删失和检测限；
- 覆盖不足：关键场景根本未观测。

每项问题记录证据、处理备选、选定处理、受影响样本和结论敏感性。
删除异常值必须有领域或测量依据，并与保留、稳健处理结果比较。

缺失处理考虑生成机制。
简单均值填补不能自动用于时间、分组或因果数据；插补模型必须在训练边界内拟合。
关键字段缺失到无法识别目标时应阻塞或降低问题范围，不得随机生成“合理值”。

数据质量报告覆盖：唯一性、完整性、范围、单位、一致性、时间顺序、键关系、类别漂移、分布漂移和代表性。
质量评分不能替代具体缺陷及其决策影响。

### 数据质量分级与策略参考

在完成逐项缺陷记录后，可使用以下分级框架辅助选择建模策略。分级是决策辅助，不能替代具体缺陷记录；每级策略选择必须登记原因和影响范围。

| 级别 | 判定条件 | 建议策略 |
|---|---|---|
| A（良好） | 缺失率低、无系统性偏差、字段完整、单位一致 | 标准流程 |
| B（可处理） | 存在可修复的缺失或编码问题，不影响核心变量识别 | 强化预处理，在训练边界内拟合 |
| C（困难） | 关键字段缺失率较高、分布漂移或覆盖不足 | 改用鲁棒方法，引入先验约束，扩大不确定性区间 |
| D（极差） | 核心变量无法可靠识别、数据严重不足或质量不可信 | 从预测转为趋势判断或定性分析；在论文中诚实说明数据限制 |

D 级降级必须在论文限制章节说明：数据缺陷的具体表现、对结论可信度的影响范围、采用的降级方法和替代证据。不能通过隐瞒数据问题来维持高强主张。

## 公开数据

使用公开数据前登记：

- 数据提供者和一手发布页；
- 下载 URL、访问时间、版本和文件哈希；
- 许可及再分发限制；
- 字段定义、单位、时区和修订政策；
- 与赛题变量的映射和不等价之处；
- 时间可用性：在目标决策时点是否已公开；
- 空间、人口或制度覆盖；
- 缺失年份、口径变化和修订断点。

优先一手机构、官方数据库、同行评审数据仓库和有版本 DOI 的来源。
聚合网站可用于发现线索，不能在无法追到源头时支撑关键事实。

检索记录字段样例（逐数据集登记：落点为 P3 `data_lineage.sources[]` 的
来源字段或对应 input artifact 的来源说明；不是独立证据类型）：

```text
检索式: ("urban heat island" AND "land surface temperature") AND (2020..2026)
来源 URL: https://…（一手发布页，非聚合页）
访问时间戳: 2026-08-22T03:00:00Z
命中与筛选: 命中 37 条 → 按"覆盖本市+年份完整+许可允许"筛得 2 个数据集
未采用说明: 其余 35 条因口径不一致/空间粒度过粗排除（原因一句话）
```

公开数据与赛题附件连接时，记录连接键、匹配率和潜在选择偏差。
代理变量必须披露为何可用、会损失什么信息，以及结论对代理误差的敏感性。

## 无数据题与仿真数据

无附件数据不等于可以编造观测。
可用证据路径包括：

- 主办方或政府公开数据；
- 文献中可定位的参数、表格或区间；
- 题面给定常数和边界；
- 机理模型允许的参数域；
- 明确标注的合成、仿真或情景数据；
- 解析推导和小规模构造例。

仿真数据登记生成模型、参数来源、随机种子策略、样本设计、噪声机制和停止规则。
必须称为“仿真数据”“合成样本”或“情景”，不能称为真实调查或实测数据。

若参数只来自宽区间，输出应反映该不确定性。
不能选一个有利点值产生确定结论。

## 文献登记与核验

每条 Citation Registry 记录至少含：

- 标题、作者、年份和出版物；
- DOI、ISBN、稳定 URL 或官方文号；
- 访问时间和版本；
- 访问等级：全文、摘要、元数据或二手引用；
- 支持的具体 claim ID；
- 页、节、表、公式或段落位置；
- 原文摘录与上下文；
- 是否有更正、撤稿、版本冲突或争议；
- 适用总体、条件和限制。

只看元数据不能支持方法细节；只看摘要不能支持全文中的精确数字或限制。
二手来源引用原始结论时，优先获取原始文献；无法获取时降低支持强度并明确访问等级。

公式和定理引用需核对定义、前提、版本和符号差异。
不能因为来源权威就跳过条件验证。

网页事实优先一手来源，保存访问时间和页面版本证据。
动态页面变化时，交付说明披露可复现限制。

### 论证替代引用

无法核实真实性、访问等级不足或内容与被引主张不符的文献不进入 Citation Registry，也不写入稿件。
对应观点改用"论证替代引用"支撑：由独立推导或已登记的 formula、result 实体给出结论，
并在稿件中显式标注"本文推导"及对应的公式编号或证据位置。
降级原因、替代方式和影响范围记入文献验证记录；检索或联网能力受限时优先降级而不是放宽核验标准，
也不为凑引用数量保留无法确认的条目。宁可少引，不可编造。

### 文献时效性参考

时效性属于专业判断，不是数量门禁：方法对比和创新定位优先选用能反映领域现状的近期权威来源，
定理和经典结论引用奠基性原始文献即可。
每条引用无论新旧都按本节要求完成真实性与相关性核验；时效偏好不能替代逐条核验，
也不能成为跳过老旧文献条件验证的理由。

## 参考文献格式一致性检查参考

当官方要求采用 GB/T 7714 或相近参考文献格式时，可逐篇核验以下各项，结果记入对应 citation 的元数据核验说明并汇总进 P3 `literature_registry`（审查角色引用时作为证据位置）；格式要求以当届官方规则为准：

- 作者名格式：中文全名规范，英文姓前名后缩写，三人以上按 `等` 或 `et al.` 规则；
- 文献类型标识：专著 [M]、期刊 [J]、学位论文 [D]、会议论文 [C]、报告 [R]、电子资源 [EB/OL] 等，与载体一致；
- 出版物名称：期刊全称或标准化缩写，全篇统一；
- 卷(期):页码：有卷期按标准格式，无卷期按省略写法；
- 出版年：四位数字，与所引用版本实际年份一致；
- 标点与中英文混排：全篇统一，避免中英文标点混用；
- 稳定标识：DOI、ISBN 或稳定 URL 经验证后保留并记录访问时间；
- 完整性：作者、页码、年份齐全，无未完成字段或占位符。

格式核验通过不能替代真实性、来源等级与内容相关性核验；两者独立完成、缺一不可。

## 私有数据不可得

关键私有数据不可访问时，先穷举安全替代：

1. 当前项目附件和隐藏工作表；
2. 用户授权范围内的本地数据；
3. 主办方、政府或机构公开来源；
4. 合法的聚合统计；
5. 机理界、文献区间或代理分析；
6. 只回答不依赖缺失字段的子问题；
7. 输出待执行的数据字典、模型和验证协议。

若摘要统计不足以恢复目标变量、关键约束或识别结构，进入 `BLOCKED`。
请求只包含最小字段、时间范围、匿名化粒度和数据字典，不索取无关身份信息。

**BLOCKED 与 D 级降级的互斥裁决规则**（与数据质量分级章节的降级路径配对使用，
两条出口不得同时适用）：

1. 先做"可响应性判定"：逐条对照 Problem Contract 的每个小问——
   在 D 级降级（预测转趋势判断、定量转定性、点估计转区间叙述）之后，
   是否仍至少存在一个能够给出诚实回答的小问？
2. 存在任何可响应小问 → 选择 **D 级降级继续**：登记降级决定与替代验证
   安排，把不可响应的小问按规则化 NOT_APPLICABLE 或限制主张处理；
   竞赛时间压力下这是默认出口。
3. 所有小问都不可响应 → 才允许 **BLOCKED**：说明穷举过的全部替代
   （上面 1–7 项逐项给出结论）、仍有效产物和精确恢复命令。
4. 判定过程登记为决策摘要；禁止因"数据不完美"或"模型效果不佳"绕过
   该规则直接停摆。

阻塞记录说明缺失项为何关键、已试替代、仍有效产物和恢复命令。
不得用 demo、公开无关样本或随机数填充私有字段后继续写确认性结果。

## 阶段验收

P3 通过前必须证明：

- 每个原始源有只读版本、来源、许可、时间、字段、单位和哈希；
- 清洗、派生、连接、筛选和划分具有完整数据血缘；
- 预处理拟合边界与时间/空间/主体/群组结构一致；
- leakage audit 无未处理红线；
- 数据错误、真实极端、异常机制和缺失没有混为一谈；
- 公开数据版本和字段映射可复核；
- 仿真数据没有冒充真实观测；
- 文献具体支持位置、访问等级和版本状态齐全；
- 不可得私有数据已用最小阻塞处理，而非虚构。

文件存在、列名齐全或脚本无报错不能自证数据有效；门禁必须解析血缘和质量实体。
