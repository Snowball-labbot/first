## 本文件负责

本文件是 P4 验证协议设计和 P6 按 Problem Contract 自动选择验证适配器的唯一规范。
每个适配器定义触发标签、必要证据、失败条件、规则化 `NOT_APPLICABLE` 条件和常见伪验证。

## 本文件不负责

本文件不选择最终模型、不生成论文、不规定固定检验数量，也不把方法名称当作质量证据。
具体阈值由题目、数据、误差成本和冻结分析计划决定；不能从本规范机械抄一个通用阈值。

## 适配器选择原则

适配器由 Problem Contract 的 `traits`、`claim_types`、`model_families` 和 `properties` 合并选择（Contract 没有 `task_types` 字段，任务语义由上述四键承载；合法值以 `python scripts/mmflow.py adapters --json` 为准）。
多标签任务运行所有适用适配器，不允许只选最容易通过的一项。

验证分为四层：

1. 程序正确性：代码是否实现了声明的公式和算法；
2. 数学或数值正确性：边界、收敛、可行性、守恒、界；
3. 统计或经验有效性：未见数据表现、校准、依赖结构、抽样误差；
4. 决策与主张有效性：结论是否足以支持论文措辞和建议。

方法是否适用优先于方法数量。
不机械强制 Sobol、Bootstrap、固定百分比扰动、固定 Monte Carlo、固定 K 折或固定重复次数。
折数由数据结构、样本量与方差稳定性决定。
运行次数由目标 Monte Carlo 误差、置信精度或预登记停止规则决定。
敏感性方法由不确定性来源、参数定义域、交互结构和计算成本决定。

所有验证输出登记其数据版本、代码、配置、随机性、样本量、指标、方向和失败标准。

## IID 群组与重复测量预测

### IID 预测

触发：`forecast` 或预测主张，且分析单位近似独立，没有时间、空间、主体或群组结构。

必要证据：

- 独立训练、验证和最终测试，或适合样本规模的嵌套重采样；
- 预处理只在训练部分拟合；
- 与最低合理基线在同一样本和指标上比较；
- 逐样本误差分布、异常失败和子群表现；
- 超参数选择与外层评价分离；
- 点估计之外的区间或重复运行不确定性。

失败：训练和评价样本重叠、根据测试结果选模型、只报告训练拟合、指标与题目方向不符。

规则化不适用：任务没有预测或泛化主张，并有合同证据。

伪验证：把训练 R² 高写成预测有效；随机切分却让同一实体的近重复记录跨集合。

工具落点：`templates/analytics/cv_backtest.py` 提供 K 折、分组 K 折（同组不跨集合）与 expanding window 时间回测的泄漏自检划分及评估汇总，可直接作为本适配器的划分实现。

### 群组、主体和重复测量

触发：`grouped`、`subject` 或 `repeated_measures`。

必要证据：

- 明确实验单位与观测单位；
- 按主体、设备、地点、批次或群组隔离；
- 群组外泛化与群组内插值分开报告；
- 依赖结构进入标准误、模型或重采样设计；
- 群组数量、大小不平衡和冷启动子群诊断。

失败：同一主体记录随机分散到训练和测试；把观测条数当独立样本量。

规则化不适用：合同证明每个分析单位只有一次独立观测。

伪验证：普通随机 K 折得到高分，却没有新主体测试。

## 时间序列与概率预测

### 时间序列预测

触发：`temporal` 与 `forecast`，或任何以未来信息为目标的主张。

必要证据：

- 明确每个预测时点可获得的信息集；
- 按时间顺序冻结训练、验证、测试边界；
- expanding window、rolling origin 或有依据的时间留出；
- 最后值、季节朴素、漂移等匹配结构的基线；
- 预测步长、季节性、冷启动和结构漂移分析；
- 所有特征在预测时点真实可用；
- 多步预测说明递归、直接或联合策略；
- 误差随预测期、时间段和场景的分布。

禁止随机打乱时间后普通 K 折。
时间序列上的随机 K 折即使分数稳定，也不能替代未来回测。

失败：未来值参与特征、归一化使用全期统计、滚动窗口越过预测时点、仅做随机切分。

规则化不适用：合同没有未来或时间外推主张，且时间字段只是不影响独立性的标签；需要有效证据。

伪验证：训练残差很小、用测试期信息构造季节因子、对已见历史点插值后称为预测。

### 概率预测

触发：`probabilistic_forecast`、区间、分位数、概率或风险主张。

必要证据：

- 适当的概率评分，如对数损失、Brier、CRPS 或分位数损失；
- 校准曲线、覆盖率或 PIT 诊断；
- 区间宽度与覆盖率同时报告；
- 类别不平衡和罕见事件分层；
- 分布假设、后验或重采样来源；
- 若多时间步，按 horizon 检查校准。

失败：只报告点预测误差却声称概率可靠；区间由任意常数宽度生成。

规则化不适用：输出和主张均为确定性点值，且没有风险或覆盖结论。

伪验证：总体覆盖接近目标但关键子群严重失配；把置信区间和预测区间混用。

## 统计推断与因果

### 参数估计与统计推断

触发：`parameter_estimate`、`inferential`、显著性、总体比较或效应主张。

必要证据：

- 明确定义 estimand、总体、实验单位和抽样机制；
- 依赖结构、配对、群组和重复测量处理；
- 效应量、方向、单位和区间；
- 模型前提诊断或稳健替代；
- 多重比较、模型选择和重复查看的影响；
- 缺失机制、权重和测量误差敏感性；
- 实际意义与统计显著性分开。

失败：把 p 值当效应大小；独立性明显不成立；只报告显著结果。

规则化不适用：任务只要求确定性计算且不做总体推断。

伪验证：正态性检验通过便宣布整个模型有效；样本量巨大导致微小差异显著。

### 因果

触发：`causal`、干预、政策效果、归因或“导致”主张。

必要证据：

- estimand、处理、结果、时间零点和目标总体；
- 因果图或等价的识别结构；
- 一致性、可交换性、重叠、无干扰等适用假设；
- 处理前协变量和禁止控制的后处理变量；
- 重叠与极端权重检查；
- 混杂、未测混杂和模型设定敏感性；
- 安慰剂、负控、事件前趋势或伪结果中的适用项；
- 不同合理规格与估计器比较。

识别条件不足时降级为关联主张。
预测精度、特征重要性和相关系数不能单独建立因果性。

失败：处理与结果定义时间颠倒、控制碰撞变量、没有重叠、把观察关联写成干预效果。

规则化不适用：合同明确不做因果解释，论文也不出现因果措辞。

伪验证：只因模型可解释或 SHAP 排名稳定便写成驱动因素。

## 精确启发式与多目标优化

### 精确或可给界的优化

触发：`constrained` 与优化任务，模型族为 exact、convex、MIP 或能提供界的求解器；若主张 `global_optimum` 则强制触发。

必要证据：

- 将候选解重新代入所有硬约束，报告最大违反量；
- 求解器状态、容差、时间和版本；
- 原始目标值、缩放和单位；
- 对偶界、松弛界、最优性 gap 或数学证明中的适用项；
- 小实例穷举或可验证解析例；
- 数值容差与逻辑可行性分开；
- 多个等价最优解或退化情况诊断。

算法返回一个解不等于获得全局最优解。
没有界或证明时，只能称“当前最好发现的可行解”或与证据一致的局部结论。

失败：硬约束违规、求解状态未知、把近似可行当严格可行、没有全局证据却声称全局最优。

规则化不适用：合同没有优化或最优性主张；只计算给定方案的性能。

伪验证：目标值看起来小；求解器显示“完成”但状态为时间上限且 gap 未知。

### 启发式优化

触发：heuristic、metaheuristic、随机搜索、遗传算法、粒子群、退火或无法给全局证书的方法。

必要证据：

- 多随机种子和结果分布；
- 相同评价次数、墙钟或资源预算下的公平基线；
- 收敛轨迹和停止规则；
- 每个候选的硬约束复核；
- 小实例精确解、强松弛界或已知基准；
- 参数敏感性和失败种子；
- 结果稳定性与最佳值分开报告。

失败：只挑最佳种子；与基线预算不等；算法不可行个体被惩罚后仍输出违规方案。

规则化不适用：使用有完整最优性证书的精确过程，且没有启发式主张。

伪验证：曲线趋平便宣布全局收敛；更多迭代自然取得更优值却称算法更强。

### 多目标优化

触发：`multiobjective_optimization`、Pareto 或多个不可通约目标。

必要证据：

- 目标方向、单位和支配定义；
- 可行 Pareto 集或近似集的非支配检查；
- 多种子、预算和前沿稳定性；
- 归一化与尺度变化影响；
- 偏好或权重变化下的决策选择；
- 最终推荐点的价值依据和替代点；
- 参考点或 hypervolume 选择的敏感性。

失败：未经价值说明把目标简单相加；推荐被另一方案支配；图形前沿包含不可行点。

规则化不适用：单一目标且无冲突决策维度。

伪验证：画出散点便称 Pareto；只展示一组偏好权重。

## ODE 与 PDE

### ODE

触发：`ode` 或连续动力系统。

必要证据：

- 量纲和状态变量定义；
- 初值、参数范围与边界事件；
- 解析特例、制造解或高精度参考；
- 时间步长收敛和求解器容差；
- 刚性、非负、有界或守恒性质中的适用项；
- 参数识别与状态拟合区分；
- 长期外推的结构稳定性。

失败：步长变化导致结论反转、状态越界、参数不可识别却给精确估计。

规则化不适用：模型不含微分动力学且没有连续时间机制主张。

伪验证：一条平滑曲线；与训练数据拟合好但初值和参数同时任意调节。

工具落点：`templates/analytics/convergence_scan.py` 执行步长减半扫描、逐级差分与 Richardson 观测收敛阶估计，并按预登记容差判定收敛。

### PDE

触发：`pde`、空间连续场、扩散、传热、流动或波动。

必要证据：

- 方程、区域、初始条件和全部边界条件；
- 量纲、离散格式和网格定义；
- 网格细化与时间步细化；
- 稳定性、守恒、非负、有界或最大值原理中的适用项；
- 制造解、解析特例或可信基准；
- 边界截断和几何近似误差；
- 求解误差与模型误差分开。

PDE 必须检查网格独立性和边界处理。

失败：只在单一网格出图、边界条件与物理叙述不一致、数值振荡被平滑图掩盖。

规则化不适用：解析闭式推导完全不采用离散 PDE 求解，并有规则化 waiver 及推导证据；若论文仍做数值场主张则不可豁免。

伪验证：图像看起来连续；网格更细时仍沿用不稳定时间步。

## 随机仿真与代理模型

### 随机仿真

触发：`simulation`、Monte Carlo、离散事件、Agent-based 或随机机制模型。

必要证据：

- 程序验证：简化情形、守恒、事件顺序和随机数使用；
- 模型验证：与真实、文献、机理或专家约束对照；
- 预热、终止、初始条件和稳态判断；
- 独立复制、公共随机数或相关样本设计；
- Monte Carlo 标准误、置信精度和停止规则；
- 随机种子和随机流管理；
- 尾部事件和稀有失败诊断。

失败：只运行一次；把仿真输出称为真实观测；没有区分随机误差和结构误差。

规则化不适用：纯解析或确定性计算，不包含随机模拟输出。

伪验证：样本数很大便认为模型真实；只比较均值而忽略分布和尾部。

### 代理模型

触发：`surrogate`、响应面、仿真替代器或近似昂贵函数。

必要证据：

- 设计点覆盖、采样策略和边界；
- 独立验证点的代理误差；
- 局部、全局和尾部误差；
- 外推识别和拒绝机制；
- 不确定性传播；
- 用原始昂贵模型复核最终候选；
- 自适应采样停止规则。

失败：在设计域外给高置信预测；只报告训练插值误差；优化利用代理误差产生虚假最优。

规则化不适用：直接使用原模型且没有代理近似。

伪验证：R² 高但极值区域偏差大；验证点来自训练设计重复。

### 深度学习与 GPU 训练的复现协议

触发：神经网络训练、GPU 加速拟合或其他可能非确定性的学习管线。

必要证据：

- 全局随机性固定：Python、NumPy、框架（如 PyTorch/TF）种子统一登记；DataLoader 与增强的随机源一并记录；
- 硬件非确定性声明：cuDNN/TF 等非确定算子要么显式开启确定性模式，要么在冻结分析计划中预登记为允许漂移；
- 多种子统计等价判据：无法完全确定化时，以 ≥3 个种子的均值±标准差报告结果，P9 复现按"统计等价"比较（均值差在合并标准差内、排序结论一致），不要求逐位一致；
- 训练过程留痕：损失曲线、早停点、验证指标和最终 checkpoint 哈希进入结构化结果；
- 推理与训练分离：论文引用的数值来自固定 checkpoint 的确定性推理，而不是"最后一次训练日志"。

失败：只跑一个种子就报告置信区间；把 GPU 非确定性漂移当作模型改进；用训练集指标充当验证结果。

规则化不适用：不涉及迭代训练或 GPU 非确定性算子的常规统计学习。

伪验证：换卡重跑数值全变却声称"完全复现"；多种子只报最好那个。

## 综合评价聚类网络与空间

### 综合评价与排名

触发：`composite_evaluation`、`ranking`、指数、评分或权重聚合。

必要证据：

- 指标定义、方向和单位；
- 缺失与异常处理；
- 归一化方法及其边界；
- 权重来源及价值假设；
- 支配关系和补偿性；
- 权重、归一化和指标删减敏感性；
- 排名反转、并列和不确定排名；
- 与外部标准或决策目标对照。

失败：正负指标方向错误；任意权重却写成客观排名；被支配方案排在前面且无非补偿解释。

规则化不适用：任务不聚合多指标、不产生排序或评分。

伪验证：不同赋权法排名相似一次便宣布稳健；只画雷达图。

工具落点：`templates/analytics/evaluation_checks.py` 提供 AHP 判断矩阵 CR<0.1 程序化判据、TOPSIS 多档权重扰动的排名稳定性与反转检测、以及"宣称最优方案是否被支配"复核。

### 聚类

触发：`clustering`、无监督分群或类型划分。

必要证据：

- 距离、缩放和混合变量处理；
- 簇数选择与不确定性；
- 重采样、子样本或扰动稳定性；
- 与随机或简单分区基线比较；
- 外部解释不使用参与聚类的同一变量循环证明；
- 小簇、异常点和替代算法诊断。

失败：缩放主导距离；仅以二维降维图判断簇；把算法簇当自然类别。

规则化不适用：没有聚类或类型发现主张。

伪验证：轮廓系数最高便证明真实群体存在。

### 网络

触发：`network`、图结构、中心性、传播或社区。

必要证据：

- 节点、边、方向、权重和时间定义；
- 阈值与缺边机制；
- 测量误差和采样偏差；
- 合理零模型；
- 社区、中心性或路径对阈值的稳定性；
- 多重边、孤立点和连通分量处理；
- 动态网络的信息时点。

失败：边定义任意；把高中心性解释为因果重要性；网络图漂亮但统计结构未验证。

规则化不适用：实体间无关系结构或网络主张。

伪验证：只展示布局图；用布局距离替代网络距离。

### 空间

触发：`spatial`、地理、栅格、邻域或空间泛化。

必要证据：

- 坐标系、尺度、边界和支持区域；
- 空间块或留区验证；
- 空间泄漏与邻近重复；
- 权重矩阵和邻域定义敏感性；
- 残差空间相关；
- 边界效应、可变支持单元和外推区域；
- 新地点与已见地点插值分开。

失败：随机点切分使相邻点跨集合；忽略坐标投影；把空间相关写成因果。

规则化不适用：位置不参与数据生成、模型或主张，并有合同证据。

伪验证：随机 K 折高分；地图颜色连续便认为模型正确。

## 图像与信号处理

### 图像类赛题（trait `image`）

触发：Contract 声明 traits 含 `image`（成像、分割、检测、遥感栅格等）。

必要证据（适配器 `image_domain_validation`）：

- 数据按拍摄/采集设备、地点或时间段划分，预处理（增强、归一化）只在训练部分拟合；
- 与最低合理基线（经典滤波/传统特征方法）在同一切分上比较，报告逐类或逐场景误差；
- 至少一次跨域或退化输入检验（噪声、压缩、光照、分辨率下降），失败案例保留并归因；
- 指标与题目要求一致（IoU/mAP/PSNR 等），报告方向与不确定性。

伪验证：仅在训练分布内报平均精度；用测试集调参；把视觉"看起来好"当定量证据。

### 信号类赛题（trait `signal`）

触发：Contract 声明 traits 含 `signal`（光谱、音频、加速度、生理信号等）。

必要证据（适配器 `signal_domain_validation`）：

- 划分按记录/设备/被试隔离，禁止同一原始记录的窗口同时进入训练与测试；
- 滤波、去噪、特征提取的参数在训练部分选择并在验证部分复核；
- 与最低合理基线（带通+阈值、经典频域特征）比较并报告置信区间；
- 至少一次鲁棒性检验（信噪比衰减、基线漂移、采样率变化），登记失败边界。

伪验证：滑窗泄漏（相邻窗共享目标）；只报告最优窗口长度；把谱峰"对得上"当统计显著。

## 解析理论模型

触发：`theoretical`、`analytic_model`、定理、界、证明、闭式公式或结构性质。

必要证据：

- 完整定义、符号和前提；
- 推导链和关键等价变换；
- 存在性、唯一性或适用域中的相关项；
- 边界、极限、特例和反例；
- 量纲和单位；
- 数值例或独立代数系统互证；
- 外部定理的准确版本、条件和引用位置。

失败：遗漏前提、循环论证、把数值例当证明、用不适用定理或公式维度错误。

规则化不适用：项目没有理论主张或解析推导。

伪验证：引用权威定理名称但未验证条件；推导结果与边界案例矛盾。

## 规则化不适用

`NOT_APPLICABLE` 只在以下三者同时成立时有效：

1. 适配器对应已知 waiver rule；
2. 当前 Problem Contract 的结构化条件满足该 rule；
3. waiver 引用当前 `run_id` 中真实、`VALID` 的合同或证据实体。

自然语言判断、空引用、其他运行实体或已陈旧证据无效。
一个适配器不适用不代表整个 P6 可跳过；仍需执行其他标签触发的验证和通用逻辑测试。

## 假设松弛分析

假设灵敏度分析检验"假设不成立时结论是否成立"。假设松弛分析更进一步——逐条放松假设，展示模型性能如何逐步退化，而非突然崩溃。

两者的区别：

- 灵敏度分析构造"假设完全违反"的替代场景，输出成立与不成立的对比表。
- 松弛分析构造"假设从紧到松"的连续变化场景，输出退化曲线。

松弛分析适用于 P6 验证阶段，作为假设灵敏度的补充而非替代：

1. 选择对模型结构影响最大且最可能被现实数据违反的假设。
2. 定义松弛轴——从完全满足到完全违反的连续参数化（如相关系数从 0 到 0.9，偏度从 0 到 3.0）。
3. 在每个松弛水平上运行模型并记录性能指标。
4. 绘制退化曲线，标注可接受退化线和不可接受退化线。
5. 若模型在合理松弛范围内性能退化可控，说明鲁棒性边界良好；若退化急剧，需在论文中严格限定适用条件。

松弛分析的输出登记为 validation evidence，绑定到假设实体和受影响的 Claim。退化曲线作为 figure 登记，图注说明松弛轴定义、性能指标和判定线。

松弛分析不替代正式的适配器验证；它提供的是模型在假设边界附近的行为信息，帮助评委理解适用范围。

## 题型默认灵敏度与稳健性管线（P4 冻结 validation_protocol 时参考）

为避免"可选模板无人选"，P4 冻结验证协议时按下表把 Contract traits 映射为
默认分析组合；登记的 `validation_protocol.analysis_pipeline`（自由文本或
列表）应说明采用/裁剪了哪些项及理由。执行深度仍由误差与预算决定，本表
只规定"至少讨论过什么"，不是固定配额：

| Contract 主导特征 | 默认管线（模板→产出） |
|---|---|
| 优化类（optimization_recommendation / global_optimum / constrained） | Tornado 单因素扰动 + 场景松弛（sensitivity_analysis.py）+ 可行性边界检验 → "结论不变域"区间 |
| 预测类（forecast / probabilistic_forecast / temporal） | expanding-window 回测（cv_backtest.py）+ 噪声鲁棒衰减曲线（extreme_test.py）→ 误差-水平线与失效点 |
| 评价排序类（ranking / composite_evaluation） | 权重扰动敏感性 + rank-reversal 检验（evaluation_checks.py 思路）→ 排序稳定性判据 |
| 微分方程类（ode/pde） | 时间步/网格收敛扫描（convergence_scan.py）+ 参数 ±10% 轨迹带 → 收敛阶与轨迹包络 |
| 仿真随机类（simulation/stochastic） | 多种子统计等价（statistical_json 协议）+ 置信半宽随 N 收敛曲线 → 稳定性证据 |
| 综合以上任一 + uncertainty trait | 全局敏感性（Sobol/代理路径按预算档位）→ 一阶/总阶指数排序 |

论文"模型评价"章引用这些管线产物时，按"扰动范围 × 指标响应 × 结论是否
反转"三件套表述；未跑到的项如实写 NOT_APPLICABLE 或限制。

## 退化场景验证协议

退化场景验证检验模型在极端参数、边界条件和退化情形下是否保持合理行为。它与假设松弛分析互补——松弛分析关注假设从紧到松的连续变化，退化验证关注离散的极端和退化情形。

### 协议步骤

1. **构造退化场景**：针对模型结构和应用场景，构造以下退化情形中的适用项：
   - 零输入或空数据：所有特征为零或样本量为 1 时模型是否崩溃或给出无意义输出。
   - 退化分布：方差为零（所有值相同）、完美共线性、单一类别、极端不平衡。
   - 边界参数：参数取理论边界值（如相关系数 = ±1、温度 = 0K、容量 = 0）。
   - 极端规模：样本量极大或极小、维度极高或极低、时间跨度极长或极短。
   - 矛盾输入：约束互斥、目标方向相反、多目标完全冲突。

2. **记录预期行为**：对每个退化场景，先写出模型在数学或物理上应产生的预期行为（如"方差为零时相关系数应无定义或报错，不应返回 0"）。

3. **运行验证**：在退化场景下运行模型，记录实际输出。

4. **判定**：实际输出与预期一致则通过；不一致则登记 finding 并评估是否影响核心 Claim。若退化场景在题目的合理参数域外，登记 `NOT_APPLICABLE` 并说明原因。

### 输出登记

退化场景验证登记为 validation evidence，包含场景描述、预期行为、实际输出、判定结果和影响分析。验证失败导致的限制写入论文限制章节。

退化场景数量由模型结构和应用场景决定，不设固定配额。简单模型可能只需 1-2 个退化场景；复杂模型或安全关键应用应覆盖更多退化路径。

## 阶段验收

P4 必须冻结所有适用适配器、指标、数据边界、比较策略、停止规则和失败条件。
P6 门禁必须证明：

- 每个任务和主张标签都映射到适配器或有效 waiver；
- 必要证据来自当前运行的生产 execution 或已核验外部证据；
- 已知伪验证没有被用作替代；
- 验证失败导致主张降级、模型修复或阶段回退；
- 运行次数、折数和图表数量由问题与误差需求决定；
- 时间、空间、主体、因果、优化和数值结构没有被普通随机 K 折或单一拟合分数掩盖。

检查器异常、未知标签或未知模型族必须返回 `ERROR`，不得默认跳过。
