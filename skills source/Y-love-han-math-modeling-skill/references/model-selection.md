## 本文件负责

本文件是 P4 基线、候选模型、模型选择规则、实验设计和冻结分析计划，以及 P5 模型比较与失败诊断的唯一规范。
它约束为什么选择某个模型，防止先看结果后改评价规则、算法堆叠和选择性报告。

## 本文件不负责

本文件不定义所有题型的详细验证适配器，不管理数据许可，不规定论文篇幅，也不替代受控执行证明。
候选模型的数学推导和实现放在项目产物中；本规范只定义选择纪律和证据要求。

## 先定义评价协议

在讨论模型优劣前，从 Problem Contract 固定：

- 分析单位与独立性单位；
- 训练、验证、测试或回测信息边界；
- 主指标、方向、单位和容许误差；
- 次指标及其仅用于诊断还是决策；
- 硬约束、不可接受失败和最低可用条件；
- 与基线比较的预算、数据和调参公平性；
- 随机性、多次运行和停止规则；
- 统计、数值和实际意义的判定方式；
- 最终测试集查看权限。

主指标必须对应赛题目标。
分类准确率不能自动替代代价敏感目标，平均误差不能自动替代尾部风险，目标函数值不能替代可行性。

若目标包含多个不可通约维度，先定义 Pareto 或分层决策，不应未经价值依据压成固定权重总分。

## 最低合理基线

每个可比较任务必须先实现最低合理基线。
“最低合理”指既简单又尊重任务结构，而不是随便输出常数。

常见基线选择原则：

- 时间预测：最后值、季节朴素、漂移或领域规则；
- IID 回归：均值、中位数、线性或正则线性；
- 分类：多数类、分层概率、逻辑回归或领域规则；
- 群组/重复测量：尊重群组的简单混合或组内基线；
- 优化：可证明可行的规则解、贪心解或小实例精确解；
- 综合评价：单指标、等权但披露价值含义，或支配关系基线；
- 聚类：随机/简单分区与稳定性基线；
- 仿真：解析近似、极限情形或简化机制；
- ODE/PDE：解析特例、低阶离散或守恒基准；
- 理论问题：直接定义、已知界、边界案例和反例。

基线必须使用与主模型相同的训练信息、评估样本和指标。
不能精调主模型却不给基线合理参数，也不能让基线看到更少数据。

复杂模型未实质优于基线时，保留基线作为主方案是合法结果。
不得为了“看起来高级”隐藏简单模型表现。

## 候选模型

候选模型数量由真正不同的结构假设决定，不按算法清单凑数。
每个候选记录：

1. 模型或方法族；
2. 对数据生成或机制的关键假设；
3. 与基线相比解决的具体缺陷；
4. 预期优势及其可证伪预测；
5. 参数、数据和计算代价；
6. 识别、数值或优化风险；
7. 适用验证适配器；
8. 明确失败条件和退场规则；
9. 可能的简化或替代方案。

候选之间应在机制、函数类、约束处理或不确定性表达上有实质差异。
只更换随机种子、优化器名称或树数量不构成独立模型思想。

优先少量可深度验证的候选。
在时间和计算有限时，对关键假设做高信息量实验，而不是把预算平均分给许多浅尝试。

## 词典序选择

模型选择采用词典序，不用一个加权分遮蔽红线：

1. 合法性与任务匹配；
2. 证据支持与正确性；
3. 任务表现和不确定性；
4. 简约性、可解释性与成本。

第一层淘汰：数据泄漏、时间穿越、硬约束违规、定理前提不满足、因果不可识别、复现失败、单位错误或非法数据使用。
无论数值分数多高都不能进入下一层。

第二层检查：实现验证、数值收敛、估计稳定性、基线公平、适配器证据和反证结果。
证据不足的模型只能保持探索性。

第三层比较主指标、置信区间或重复运行分布、实际效应和最坏场景。
不能只报告最佳种子、最佳折或最佳后验样本。

第四层在表现接近时偏好更简单、可解释、计算更稳定且易复现的方案。
增加复杂度必须对应可量化收益或必要结构。

选择结果记录保留所有候选的命运：采用、保留为对照、降级为探索性或淘汰，以及具体证据。

## 冻结分析计划

P4 结束前冻结分析计划，至少包含：

- 数据版本和划分实体 ID；
- 预处理拟合边界；
- 基线和候选模型；
- 主指标、次指标、方向、单位和聚合方式；
- 超参数搜索空间与预算；
- 随机种子策略；
- 适用验证适配器；
- 比较策略与数值容差；
- 多重比较或选择调整；
- 成功、失败、停止和降级标准；
- 哪些结果为确认性，哪些为探索性；
- 是否已查看最终测试。

冻结是防止结果驱动分析，不是禁止修复真实错误。
修复代码、数据错误或错误假设时必须记录 amendment，并重新界定确认性证据。

最终测试在冻结前不可用于调参、选特征、选模型、定阈值、选图或挑叙述。
发现测试泄漏后，旧测试不再是确认性测试；需要新留出数据、嵌套验证或主张降级。

## 计划修订与选择性报告

任何查看结果后的计划变化都登记：

- amendment ID 和时间；
- 已查看哪些结果；
- 变化前后内容；
- 修订原因：错误修复、可行性、资源、领域发现或表现驱动；
- 受影响的主张和证据；
- 是否需要新数据或新外层验证；
- 修订后哪些分析只能是探索性。

选择性报告包括只保留最佳模型、最佳随机种子、最佳时间窗、最佳指标或最漂亮情景。
必须保留失败尝试与淘汰依据，并在主结论中使用预登记的主指标。

若探索发现产生新假设，可明确标注探索性，再用独立验证数据或新的模拟设计确认。
不能把同一数据上的发现和验证写成独立证据。

## 失败诊断与回退

模型失败先定位类别：

| 类别 | 典型证据 | 回退方向 |
|---|---|---|
| 数据 | 缺失、错误单位、漂移、覆盖不足、标签错 | P3 |
| 公式 | 维度错、约束漏、前提不满足、不可识别 | P2 或 P4 |
| 实现 | 单元测试失败、解析特例不符、索引错 | P5 当前实现 |
| 求解 | 不收敛、不可行、病态、局部最优 | P4/P5 求解设计 |
| 评价 | 指标不对应目标、划分泄漏、方差过大 | P4 |
| 资源 | 内存、时间或精度预算不足 | 降阶、抽样或等价算法 |

诊断以日志、最小复现、边界测试和结构化结果为证据。
不要在未找到根因时同时更改数据、模型和指标。

失败尝试登记为 execution 和 finding，不删除。
替代模型使用新 attempt，旧结果保持历史状态；若上游源变化，沿 Lineage 传播陈旧状态。

## 复杂度和创新边界

创新是解决题目关键困难的新结构、证据、推导、识别、算法或决策洞察，不是算法数量。
不得设定固定创新数量、定理数量、图数或模型数。

模型复杂度只有在以下情形合理：

- 简单基线暴露了可重复的结构性偏差；
- 题目硬约束需要更复杂表示；
- 不确定性或依赖结构不能由简单模型表达；
- 机制知识提供可验证结构；
- 复杂模型在公平预算和独立证据上产生实质收益。

若复杂模型只带来微小、方差很大的提升，优先主张“与基线相当”或使用简单方案。
理论深度来自准确前提、非平凡推导和与问题的联系，不来自引用更多定理名称。

## 复杂度-性能权衡展示

评委常问"复杂模型是否真的比简单模型好很多"。复杂度-性能权衡分析用一张图回答这个问题。

两种形式：

- **Pareto 前沿**：当同时优化多个目标（精度提升 + 复杂度降低）时，散点图横轴为模型复杂度（参数数量或训练时间），纵轴为性能，Pareto 前沿高亮。
- **肘部曲线**：当单一复杂度参数变化时，折线图横轴为复杂度参数，纵轴为性能，标注边际收益递减的肘部位置。

权衡展示适用于 P6 验证或 P8 论文中，作为候选模型比较的视觉补充：

1. 复杂度指标必须与题目目标和计算约束相关，不能只用参数数量代替。
2. 性能指标使用冻结分析计划中的主指标。
3. 每个点绑定到对应候选的 Execution 和 Result。
4. 标注最终选择的位置和选择理由。
5. 若复杂模型只带来微小提升，图中的肘部位置支撑"与基线相当"的主张。

权衡图不替代词典序选择；它展示的是第四层（简约性）比较的视觉证据，不能遮蔽第一层（合法性）红线。

## 阶段验收

P4 门禁必须确认：

- 每个可比较任务存在结构合理的基线；
- 候选模型具有可证伪差异和失败条件；
- 选择使用词典序，红线不能被总分抵消；
- 数据划分、指标、预算、验证和停止规则已冻结；
- 最终测试查看状态明确；
- 比较和复现容差已预登记；
- 所有 amendment 可追踪，探索性结果没有冒充确认性。

P5 模型选择输出必须引用真实 execution、result 和验证证据。
报告中“效果最好”不能由一张手工表或文字自证；必须按冻结规则重新计算。
