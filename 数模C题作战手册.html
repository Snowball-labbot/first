4三人分工与协作

🧠 建模手

决定论文上限

  • 读题拆解子问题、定义变量与假设
  • 选定模型体系并说明为什么选它
  • 设计验证方案与灵敏度分析
  • 给出结果的实际含义解读

💻 编程手

C 题的核心发动机

  • 数据清洗、特征工程、EDA
  • 模型实现与调参（Python 为主）
  • 出版级出图（矢量 SVG + 300dpi PNG）
  • 记录随机种子、依赖版本 → 复现清单

✍️ 论文手

决定论文下限

  • 全程同步写作，不等结果
  • 摘要（最后精修，反复打磨 ≥5 遍）
  • 图表编号、公式、参考文献规范
  • 终稿数值一致性 + 排版质检
协作铁律：① 共用一份子问题清单，做完一问打勾一问；② 编程手每出一张图立刻丢群里，论文手立刻贴进稿子（不要攒到最后）；③ 建模手发现模型跑不通要果断降级换成能跑通的简单模型，宁可模型简单也不要结果空白；④ 任何争议由队长在 10 分钟内拍板，不纠缠。

5C 题专项攻略

国赛 C 题（大数据分析）与美赛 C 题（Data Insights）对照 —— 你主攻的题型。

🇨🇳 国赛 CUMCM · C 题

定位：大数据 / 数据分析类，附件通常给出 Excel/CSV，数据量从几千到几十万行。近年真题：

2024农作物种植策略（优化 + 风险评估）
2023蔬菜类商品自动定价与补货（关联分析 + 预测 + 优化）
2022古代玻璃制品成分分析与鉴别（分类 + 敏感性分析）
2021生产企业原材料订购与运输（数据处理 + 规划）
2020中小微企业信贷决策（评价 + 优化）
规律：C 题基本是「数据分析 → 评价/预测 → 优化决策」三段式。最后一问几乎必然落到决策建议，不是纯预测。

🇺🇸 美赛 MCM · C 题（Data Insights）

定位：给定数据，要求"从数据中提炼洞察"。通常数据量大、类型杂（含文本/图像/时间序列）。近年真题：

2026Data With The Stars（粉丝投票估计）
2025奥运会奖牌榜（预测 + 评价 + 反事实分析）
2024网球比赛"动量"（随机过程 + 预测 + 检验）
2023Wordle 结果预测（时间序列 + 情感分析）
2022黄金与比特币投资（时间序列 + 投资组合）
差异：美赛是 96 小时（4 天）、全英文、25 页上限（含附录代码）、结论需给直接建议。评审极度看重摘要质量与假设合理性 + 灵敏度分析，且对"创新可容错"——有创意的错误论文也可能获奖。

C 题标准解题流水线

1数据清洗缺失/异常/重复/量纲，留痕
2EDA 探索分布·相关·趋势·分组
3特征工程构造/编码/降维/选择
4建模求解分类·预测·评价·优化
5检验对比多模型对比 + 误差指标
6稳健性灵敏度 + 扰动 + 交叉验证
7决策建议回答题目每一小问
C 题拿分三板斧：
① 把数据处理过程写进论文——C 题评审会看你是否认真处理了异常值与缺失值，这是免费的分数；
② 每个模型都配对比与检验——单一模型直接给结论是最常见的扣分点，加一个对比模型（如 ARIMA vs LSTM vs 灰色预测）立刻提升档次；
③ 图要出版级——国赛论文第一印象几乎由图决定。统一配色、中文宋体/英文 Times、坐标轴带单位、300dpi 以上、优先矢量图。

7论文结构与写作要点

章节要点篇幅
摘要（独立一页）全文最重要的一页。四段式：① 问题背景与要解决的问题 ② 采用的方法与模型（点名具体算法）③ 得到的关键结果（给具体数字）④ 结论与建议。最后写，改 5 遍以上。1 页
一、问题重述用自己的话复述，不要照抄题目；明确列出题目给了哪些数据、要求回答哪几个问题。0.5 页
二、问题分析画技术路线图（必画！），逐问说明思路与模型选型理由。1–1.5 页
三、模型假设每条假设都要有理由，且必须是"为建模不得不做的简化"。卡住的地方可以写进假设。0.5 页
四、符号说明符号表，全文统一，避免一处多义。0.5 页
五、数据处理C 题重点章节。数据来源、清洗规则、异常值处理、缺失填补、描述性统计表、EDA 图。2 页
六~八、模型建立与求解按子问题分节。每问：模型原理 → 公式推导 → 求解方法 → 结果图表 → 结果解读。每问配对比模型。8–10 页
九、模型评价与改进优点 / 缺点 / 改进方向。缺点要真说，改进要具体。配灵敏度或稳健性分析。1–1.5 页
十、结论与建议呼应摘要，逐条回应题目的每一个小问，给出可执行的建议。1 页
参考文献规范引用，GB/T 7714 格式。数据、算法、文献均需标注。0.5 页
附录（支撑材料）核心代码、补充图表、中间数据。放支撑材料压缩包，不占正文页数。—
终稿质检 5 查：① 摘要与正文结论数字是否一致；② 全文搜索有无姓名/学校/队号残留；③ 图是否有编号+标题+单位，正文中是否都引用了；④ 表格是否用三线表，数字是否有单位；⑤ 转 PDF 后是否乱码、图是否清晰、页数是否符合要求。
