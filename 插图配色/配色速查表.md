## 三、连续色标（热力图用，代码里 `mgstyle.CMAP`）

- **电价** `price`：#FDF9EE → #F7FBC9 → #F5EBAE → #F0C284 → #EF8B67 → #E3625D → #B54764 → #992224（越贵越红）
- **光伏** `pv`：#34183E（夜）→ #3E608D → #7895C1 → #A8CBDF → #F5EBAE → #F0C284 → #FFC04D（正午）
- **负载** `load`：#F5F8FB → #D6EFF4 → #A8CBDF → #7895C1 → #3E608D → #34183E
- **SOC** `soc`：#F3F1FA → #B7B7EB → #8074C8 → #4E1945
- **净负载** `net`（双向）：#3E608D（盈余）→ 白 → #992224（缺口）

## 四、用法

```python
from mgstyle import set_style, C, LINE, CMAP, PALETTES, style_axes, savefig
set_style()                        # 一键中文字体 + 顶刊样式
ax.plot(h, load, color=C["负载"])  # 语义取色
ax.plot(h, pv,  color=LINE["光伏"])# 线条深色版
plt.imshow(mat, cmap=CMAP["price"])
```
