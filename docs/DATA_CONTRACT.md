## 2. 时间信息与防止未来信息泄漏

建议统一为十分钟区间，并明确保存：

| 字段 | 含义 |
| --- | --- |
| interval_start / interval_end | 区间起止时间 |
| target_time | 被预测或被调度的时间 |
| issued_at | 预报的发布时间 |
| observed_at | 实际观测可用的时间 |
| decision_time | 决策生成时刻 |
| model_fit_until | 拟合该预测器使用的最后观测时间 |

预测输入的发布时间和观测可用时间不得晚于决策时间。十分钟实际平均功率通常在区间结束后才完整可知：若仿真允许在区间内即时平衡，应明确这是实时调节近似，不能将它混入区间开始前的已知信息。

输入时标从 `00:10` 到 `00:00+1`。建议内部暂按“区间右端点”解释：首点对应当日 00:00—00:10。**这仍是待核对的工作假设。**

模板存在疑似错位标签，例如 result1 首行为 `0:10-0:20`、末行为 `0:00+1-0:10+1`；其他模板也有类似跨日标签。不能只凭列号抄写。应建立显式映射表，核对原题或后续说明，并记录采取的解释。本次未修改模板。

附件 3 是整点功率预报。暂采用分段线性插值并明确边界处理，将其转换为十分钟平均功率／电量；不要把一小时功率直接填成十分钟电量。首个预报目标点、发布时刻与跨度需按真实表头核对。

## 3. 共同物理模型

时间步长 Δt＝1/6 小时。若输入视为区间平均功率，则电量＝功率×Δt。

以下全部电量变量单位为 kWh，电价 p 单位为元/kWh：L 为负载，V 为光伏，g 为普通购电，e 为紧急购电，c 为母线送入电池的充电电量，d 为电池送回母线的放电电量，w 为未利用电量，S 为电池内部储电量。

\[
g_t+e_t+V_t+d_t=L_t+c_t+w_t,\quad w_t\ge0.
\]

\[
S_{t+1}=S_t+\eta_c c_t-d_t/\eta_d.
\]

题面参数：额定容量 12,000 kWh，允许储电范围 1,200—10,800 kWh，最大充放电功率 5,000 kW，2025-01-01 00:00 初始电量 6,000 kWh。

若上限定义在母线侧，用二元变量 z 表示充电状态：

\[
0\le c_t\le833.3333z_t,\quad
0\le d_t\le833.3333(1-z_t),\quad z_t\in\{0,1\}.
\]

程序应使用 5000/6 的精确表达而非上述展示用四舍五入值。

“充放电效率 90%”暂按 ηc＝ηd＝0.9，往返效率为 0.81；如果按总往返 90% 理解，则需另一组参数。两种口径不能混用，可作为敏感性分析。

不自行加入售电收益。未利用电量应尽可能分清弃光与未使用计划电量，以便解释成本。普通购电计划和物理使用可以不同，但费用按题意计入计划量。

第一问日末 S 等于日初。第二至四问采用跨日连续 SOC；日末目标或终端价值属于需明确的策略设置，不每天凭空重置。2 月 1 日初值通过共同的因果一月热身策略获得；冷启动规则应预先写明。比较预测器时保持共同评价起点一致，并在整个评价期保留各自之后的 SOC 演化。

## 4. 费用账本

第二问：C＝Σ p×原计划购电量＋Σ 5p×紧急购电量。正常计划富余不能事后退款，除非题面所允许的调整流程明确发生。

第三问需要记录 `plan_version`、`effective_from`、`old_quantity`、`new_quantity`、`increase`、`decrease`、计费价格与调整费用。一次调整中，原量 q0、新量 q1：

- 若取消部分退原款，另付 50% 违约费：普通及调整费用为 p×min(q0,q1)＋0.5p×(q0−q1)^+＋1.5p×(q1−q0)^+。
- 若原款不退，另收违约费：费用为 p×q0＋0.5p×(q0−q1)^+＋1.5p×(q1−q0)^+。

两式随后均需加上紧急购电费用。这里的正部 x^+＝max(x,0)。题面没有充分展开退款及多次调整的清算细节；**不得把上述任一解释当作已经核实的唯一规则。**

建议优先论证“取消退原款并支付违约费”，但多轮调整仍需独立定义原始／上版计划基准和购电批次结算，避免先增购再取消被错误退款、同一部分重复收费或出现无意义的调整套利。在确定清算规则前，不报告第三、四问的已验证节省金额。

第四问还要区分：预测价格用于决策，实际价格用于所选结算规则下的评价。附件是按供电时段给出的单一价格序列，不是同一交付时段在各交易时点的完整报价面板。可以暂按“交付区间实际价格作为 p，再乘对应费用系数”评价，但必须列为假设；不能虚构日内报价数据。若另用决策时价格结算，应清晰说明并单独分析。
