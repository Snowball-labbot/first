## 复现

在仓库根目录使用项目Python环境依次运行：

```powershell
python -m src.v9_inventory
python -m src.v9_figures
python -m src.v9_document
python scripts/v9_render.py
python -m src.v9_verify
```

原生Word导出需要Windows及Microsoft Word；其余步骤使用numpy、scipy、matplotlib、python-docx、lxml、Pillow和PyMuPDF。修改图或版式后必须重新导出并核验PDF。
