## 重建顺序

在仓库根目录使用已安装依赖的Python环境运行：

```powershell
python -m src.v4_report
python -m src.v4_overview
python -m src.build_v4_word
python -m src.v4_render
python -m src.v4_verify
```

Word构建依赖数模DOCX工具及Pandoc（通过pypandoc定位），PDF导出依赖Windows已安装的Microsoft Word及pywin32。正文、数据、图和公式来源在 `artifacts/v4/word_build.json` 中记录；QA临时文件位于忽略目录 `.qa/v4/`。V3输入文件保留。PDF排版在不同Word或字体环境下可能有页数差异，应重新导出与核验。
