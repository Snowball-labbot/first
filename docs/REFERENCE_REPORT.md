# 用户提供的算电协同报告：可借鉴的方法

材料：`C题_面向算电协同的多目标调度优化.pdf`，14 页。标题为《双层多保真 Pareto 搜索与互补消元：面向算电协同的多区域调度优化》，首页标注 2026 年第七届华数杯。

**这不是当前国赛 C 题的题面或已核验答案。** 文内将自身称为参考稿；没有证据证明获奖，也未在本次复现其结果。它研究多区域数据中心任务、电力、储能等联合调度，不能直接移植所有假设。

## 1. 各部分实际用了什么

| 报告位置 | 所做工作 | 方法与代码作用 |
| --- | --- | --- |
| 第 4 页，第一问 | 预测 6 区域 × 3 任务类型的 18 条小时序列 | 比较日同期、周同期、日周混合及含滞后／时间特征的岭回归；按验证 MAE 选模型 |
| 第 4—6 页，任务调度及第二问 | 为任务选择地区、开始时刻，满足资源、时限等约束 | 可行插入与启发式评分，比较成本、碳、综合等策略 |
| 第 7—9 页，第三问 | 给定负载后安排储能和电力流 | 线性规划、SOC 方程、功率容量限制，使用 HiGHS 求解 |
| 第 9—12 页，第四问 | 比较多目标任务与能源联合安排 | 低成本近似评价、NSGA-II／差分进化搜索、代表方案精细复核及敏感性分析 |

该报告的预测部分没有使用 GRU 或 LSTM。图表中的“AI 训练任务”是被调度的计算负载类别，不等于作者正在训练一个神经网络预测器。NSGA-II 和差分进化也是优化搜索算法，不是神经网络。

报告对预测按时间划分训练、验证、测试，再根据验证误差选模型。其验证和测试各只有 24 小时；可以借鉴时间顺序和对照思路，**不要把这么短的划分直接套到本题全年十分钟数据**。

## 2. 它怎样使用代码

第 13—14 页列出支持材料索引：

- `audit_inputs.py`：输入检查。
- `problem1.py`—`problem4.py`：各问模型与求解。
- `benchmark_exact.py`、`post_analysis.py`：小规模精确比较、事后分析。
- `visualize_results.py`、`generate_structure_diagrams.py`：可视化。

这些是 **PDF 列出的文件名，本仓库没有这些源文件**。附件只有伪代码与方法说明，不能据此声称已检查完整源码、测得其运行时间或复现了文中数值。

可借鉴的流水线是：读取并审计输入 → 预测 → 优化／调度 → 独立约束审计 → 保存结果 → 生成图表。不是把数据交给一个算法后直接让语言模型编写结果。

## 3. 哪些地方不能直接照搬

- 报告允许售电并计入收入，某些方案出现负净成本；当前国赛题面没有给出售电收益，不能自行添加。
- 报告在线性规划后做充放电互斥修复，再重新平衡电流。本题优先用二元变量直接约束互斥；修复解需要重新检查可行性和费用，不能直接声称保留原 LP 最优性。
- 报告某方案声称实现零外网购电，这是其数据、光伏、容量与规则下的结果。不能据此推断当前微网题也能全年不买电。
- 报告用小规模精确模型评估启发式质量；这不能证明完整大规模方案全局最优。

## 4. 对本题最直接的启发

第一问先把物理模型做对；第二问用简单预测与岭回归建立能复算的调度基线；第三问分析预报更新和调整费用；第四问增加 GRU，并沿用统一费用账本和公平评价。

论文的重点是“模型为何对应题意、如何求解、怎样核验、结果支持什么”，而不是照着参考稿堆同样的算法名称。
