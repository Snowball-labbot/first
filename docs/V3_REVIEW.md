## 第三、四问结算

以午夜原计划x、最终有效普通购电量y、紧急量e、实时价p计费：

    p min(x,y) + 0.5p max(x-y,0) + 1.5p max(y-x,0) + 5pe
  = px - 0.5p max(x-y,0) + 1.5p max(y-x,0) + 5pe。

取消部分仍付半价；不是原计划全额收费后再加半价罚款。中途修订版本保留供追溯，最终相对午夜原计划净结算，避免调增又调减重复收费。Modex正文及代码与上述公式一致；用户提供的对标报告中“Modex不退款”的描述不准确。V1/V2的差别主要是逐次修订累计结算。V3在每次优化和最终账本均使用新口径，已完整重跑，不能只替换论文数字。

## GRU与最优界

价格预测的四个发布时刻，GRU的MAE均优于同期和岭回归。加权MAE分别为GRU 0.0436596、岭回归0.0475050、同期0.0564822元/kWh；GRU比同期下降22.70%，比岭回归下降8.09%，不是比岭回归下降23%。

第四问滚动费用：同期14,314,442.48元、岭回归14,320,233.59元、GRU14,312,347.70元。GRU相对同期节省2,094.78元；配对分块bootstrap区间跨零，因此精度优势清楚，全年费用优势较小。保留一月选定的同期为主策略，将GRU作为对照，不能用全年结果回选主策略。

新增严格的名义规划比较：在相同预测供需、余量、初末状态与物理可行域内，以真实价格求LP下界J*。任一预测价格方案的真实价名义目标J满足J≥J*，故J−J*给出该可行域内剩余费用改进的上界。GRU对应合计136,842.64元、占其名义费用1.002%。这个数值是论文突出结论；它不等于含未知供需、紧急购电和滚动执行的实际全年成本的全局最优差距。Modex的真实电价执行对照也是反事实比较，不能直接充当实际成本的严格最优界。
