# C 题报告配色与图形规范

来源：用户本机 `CUMCM2026Problems/插图配色/配色速查表.md`。此次保存其 C 题语义颜色和连续色标，供更换账号后延续风格。原表关于期刊和色卡出处的描述属于原材料说明，本次未独立核实，不作为论文事实引用。

## 1. 全文统一的颜色

| 对象 | HEX | 辅助区分 |
| --- | --- | --- |
| 光伏填充 | #F0C284 | 光伏线条 #E8A33D |

| 净负载 | #7895C1 | 标清正负方向 |

价格模型对照可使用“基线灰、岭回归蓝、GRU 紫、实际值红”，但同图同时表示不同物理变量时，优先使用物理变量的固定颜色，以线型区别预测器。不要只靠红绿区分关键信息。

## 3. 建议图表

第一问：负载／光伏／购电时间曲线、SOC 与充放电、费用对比。

第二问：预测与实际、预测误差、费用分解、余量与紧急购电之间的关系。

第三问：各版预报或计划对比、更新时间标记、调整费与紧急费用的变化。

第四问：同期／岭回归／GRU 的样本外误差及实际费用对比、价格尖峰附近的预测和调度、按月的稳定性。

统一白底、淡网格、清晰中文字体和单位；本机可用 Microsoft YaHei，换环境时指定可用替代字体。可发表图形优先导出 SVG/PDF，同时提供至少 300 dpi PNG。图注记录数据范围和实验编号。

所有图形必须来自实际输出；方法示意图可以画，但不得用模拟示例冒充比赛结果。
