本文件记录2026年9月12日的模型复核。完整论文仍命名V5；最新数值在`artifacts/v5b/`，修改前V5的数值保留于`artifacts/v5/`。图片和参考PDF是思路材料，其表述与费用不能代替题面或本项目的可复现结果。

| 提醒 | 本项目核验 | 结论 |

## 2. 第一张图片：周期、窗口与非对称预测风险

**周期性值得分析。** 附件负载同槽七日相关0.9855、日总量七日相关0.9880，支持同周日及星期特征。光伏同槽一日相关0.9923，但其中包含共同昼夜形状；不能把原始相关直接当成增量预测收益。完整数值见`periodicity.csv`。

**训练窗口不必机械取7的倍数。** 保持岭回归、70%余量和原即时执行器，仅改窗口，28、56、60、84日的全年费用分别为14,211,345.15、14,152,541.05、14,132,612.16、14,033,154.46元。84日值得未来验证，但56日仍劣于60日。现有一月历史不足，各窗口验证费完全相同，因此保留既定60日窗，未把全年最低者偷换为验证选定模型。该敏感性还没有与新价值控制器做全组合实验，不能把两者节省直接相加。

**RMSE不等于购电决策损失。** 单时段、无储能、无残值、连续需求分布下，目标为p·g＋5p·E[(D−g)⁺]，一阶条件给出F(g)=0.8。它解释低估代价较大，却不是带储能、滚动合同的统一最优分位数。模型保留预测MAE/RMSE作诊断，以实际购电费验证风险余量；一月选择70%，90%余量反而因多购增费。“保守”应指费用风险控制，不能无条件多买或少买。

**不存在仅凭摘要即可核对的统一全年数值。** 比较费用必须同时匹配时间边界、初末SOC、信息可见性、计费、预测器及动作权限。

## 3. 第二、三张图片：状态价值函数是否更好

| 内容 | 修改前V5 | 本次采用或保留的处理 |
|---|---|---|
| Q1确定性最优 | 等价LP＋MILP核对 | 加入无SOC网格连续凸分段线性DP，14个初始价值折点；九个初始库存与MILP一致。费用仍35,126.85元，没有凭DP名称制造节省 |
| Q2实时储能 | 遇缺口尽量放电 | 过去28日配对残差路径的后续价值均值，按当前库存与当前缺口决定放电；全年再省141,219.56元 |
| Q3滚动 | LP调单＋月度负载选择 | 固定合同DP直接套用全年增费149,493.07元；改用含下次调单机会的价值估计后省9,844.62元 |
| Q4日前 | 岭回归价格＋即时执行 | 未来用预测价、当前用已揭示价的路径价值控制，再省115,042.37元 |
| Q4滚动 | 同期价格＋滚动LP | 固定合同DP增费142,813.92元；可调单价值估计再省5,444.97元 |

“LP只能给轨道、DP才能给全域”过于绝对。一次LP的对偶量通常描述局部敏感性，但参数化LP也可刻画全状态价值；确定性LP和DP并非互相排斥。我们保留LP制定合同，以连续价值表示辅助状态响应，论证更准确。

图片中的随机执行器本身也写明“历史路径平均近似”。本项目同样没有将其改称精确随机最优：历史场景内部知道该条场景的后续形状，真实在线动作并不知道实际未来；仅SOC也不保证足以描述具有相关误差的随机状态。

**关键失败实验及修正。** 下次预报到来后可以以1.5倍价格增加普通合同，若仍把全部未来不足按5倍紧急价计值，会过度保留库存。滚动改进把下次发布后的场景缺口价格估为1.5倍，之前仍为5倍；它只改变价值近似，实际紧急电价始终5倍，取消/新增规则完全不变。该设计是在观察固定合同方案的一月失败后追加，不属于最初预注册的候选；全过程属于同年度开发复核，不能包装为完全独立测试。

图片报出的35,126.95、13,566,395.37、13,024,699.25、14,269,748.14、13,716,889.66及离线下界12,780,883.29元，缺少配套输入与逐时账本，**未在本项目复现**。不能因其数字更低便认定更优，也不能将其当成我们的实验结果。Q1约0.10元差异涉及本项目此前已修正的模板时间对齐，当前口径详见V3审计。

所有时段的价格和终端价值系数同时乘同一个正数，只会把目标同比缩放，不改变可行域内最优解集合。任意分时价格误差不满足这个前提，不能由此断言预测价格无价值。共同比例缩放与实际未来价格扰动的针对性测试均已通过。

## 4. 第四、五张图片：写法与所谓“包装”

采用“同一物理库存、不同可见信息与合同权限”的四问递进写法，比堆砌互不相连的模型名称更清晰。本次重写摘要、逐题分析与结论，并增加Q1价值表示、Q2路径控制和Q3合同权限分析。

不采用未经建模的“金融期权定价”包装。储能确有跨期灵活性，但本项目没有风险中性测度、无套利定价或市场完备性等金融模型；增加这些名词不会自动改进调度。图片对奖项的判断也不构成可验证证据。正文使用有结果支持的机制解释，复杂性留在确实改变动作和费用的地方。

## 5. 与用户提供的Modex PDF的区别

原`26CModex4.8+5直出.pdf`与本次截图摘要并非同一数值版本。原PDF摘要采用同型日均值、报童0.8分位与600 kWh应急预留，Q2报告约1,410.51万元；Q3滚动约1,452.65万元；Q4两分支约1,489.44与1,521.03万元。不能将原PDF与截图中的DP新摘要混为一份已核验报告。

我们吸收其问题递进、成本不对称和先解释机制再报告结果的表达；保留本项目可回放的岭回归与分位数校准，并将固定应急预留改为状态与后续价格共同决定的放电控制。固定600 kWh预留与本文价值策略没有在同一实验管线完整重跑，因此不声称已证明优于该PDF的所有策略。跨文档费用大小也不作为算法排名。

## 6. 实际选择与证据范围

本次采用的四个控制器均在一月验证优于原执行器；Q2零终端价值与夜间价值同分，按候选先后选零值，未因后者全年再便宜50.94元而回选。全年固定自适应负载与84日窗虽有更低消融费用，仍未替换已定义的选择规则。

因此“最优”严格区分：第一问为所列确定性模型的全局最优；其余为当前候选及开发验证规则选出的可行策略，未证明整个不确定调度问题的全局最优。数值证据见`artifacts/v5b/verification.json`、`improvement.json`及各候选账本。比较细节保留本文件，正文集中呈现模型、机制、结果与必要边界。
