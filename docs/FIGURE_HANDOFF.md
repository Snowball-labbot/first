# 第一二问图表交接

当前授权的初稿已经包含四幅可核验基础图。后续图表 Agent 依据用户新指令做美化或扩展，不重新决定数学结论，不改模型和费用。

| 图 | 图表目的 | 权威数据 | 可调整内容 |
| --- | --- | --- | --- |
| q1_dispatch | 说明单日购电安排与 SOC 约束 | artifacts/q12/q1_intervals.csv | 面板比例、图例、线宽、字体 |
| q2_validation | 说明少紧急购电不一定意味着总费低 | artifacts/q12/policy_validation.csv | 费用单位、标注与线型 |
| q2_forecast | 展示指定日负载及光伏预测误差 | artifacts/q12/selected_dates_plot_data.csv | 可扩展为四个指定日期，但标明样本 |
| q2_cost_comparison | 比较四策略普通费与紧急费 | artifacts/q12/q2_summary.json | 排序、布局、堆叠费用标注 |

基础绘图源为 `src/deliver_q12.py`，语义配色见 `VISUAL_STYLE.md`，PNG 为 300 dpi，SVG 保留文字。初稿引用的图号顺序为调度图、验证图、预测图、费用图。

交接注意：

- 日前预测虚线、实际值实线；任何漂亮的新曲线都必须来自真实结果，不能用生成式图像工具重画数据。
- 主策略是 **ridge_q0.7**，这是由一月验证选择的结果，不是事后选全年最优。
- “紧急区间数”是十分钟区间数，不能画成同样数量的独立事件。
- spill_kwh 是未利用总电量，不能直接命名为“弃光量”。
- SOC 是 kWh；若换成百分比，应明确用额定 12000 kWh 作分母。
- 单日图不代表全年的平均表现，不用精选日图替代全部误差指标。
- 每次新图写明使用的数据文件、筛选日期、字段、单位和变换。更新图注后同步核对正文引用。
- 在独立分支或不重叠文件中工作；不要覆盖别人正在修改的模型与原始结果。

推荐后续补图：四个指定日期的小倍图、按月费用及紧急费用对比、余量与未利用电量之间的关系。它们应回答新增分析问题，不为凑数量重复已有图。
