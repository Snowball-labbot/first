## 3. 已澄清的关键问题

1. 第一问用线性规划／MILP，**不是线性回归**。已给曲线作为输入，决策是何时买多少电、何时充放电。
2. 第二问最小化计划购电费与紧急购电费之和。零紧急购电可以作为保守对照目标，不能直接等同于最优；完全不向外网买电还需要满足逐时能量可行性。
3. 第二问可尝试岭回归预测负载和光伏，但仍需接上调度与实际运行仿真。
4. 第三问核心是新预报的价值能否覆盖调整成本，适合 MPC；附件 3 已给光伏预报，无须为了使用它而训练神经网络。
5. 附件 4 确实有全年、每日 144 个时段的波动电价。但“文件给出了事后实际价格”不自动意味着日前已知道全天价格。
6. 第四问可比较神经网络和非神经网络，评价预测误差及最终调度成本，保持信息条件、费用口径与物理约束一致。
7. 参考 PDF 是 2026 华数杯算电协同参考稿，不是本届国赛 C 题的答案；其完整支持代码没有包含在用户给的 PDF 中。

## 4. 接手后应优先处理

当前只需要继续讨论或修改文档时，不启动以下模型任务。收到执行指令后按顺序推进：

1. 定位输入文件，核对指纹、sheet 名、列名、时间与单位；参照 `DATA_CONTRACT.md` 建立明确时间映射。
2. 把尚有歧义的约定写成配置与假设：效率解释、模板时间标签、取消购电退款规则、多次调整计费、波动价格的结算时点、跨日 SOC 及终端目标。
3. 实现第一问单日 MILP，并独立复算费用、能量平衡、SOC、互斥和终端条件。
4. 实现因果仿真和第二问同期预测基线；先跑连续一周，再接入岭回归与风险余量。
5. 接入第三问预报版本与滚动调整，比较日内更新时间的子集。
6. 复用上述框架，开展第四问同期／岭回归／GRU 电价预测实验。
7. 在模型与口径稳定后完成 334 天回测、模板导出和论文图表。
