# 四问建模方案

状态：待实现、待验证。下文区分题目条件与推荐方法；不要据此填造数值结果。

## 1. 整条链条：预测 → 优化 → 运行 → 评价

- **预测**回答未来负载、光伏或电价大概是多少。同期方法、岭回归、树模型、GRU、LSTM 都可用于其中部分任务。
- **优化**回答每个时段买多少电、充多少、放多少。主方法是线性规划或混合整数线性规划。
- **运行仿真**用之后实际发生的数据检验计划，保留真实电池状态、紧急购电和调整过程。
- **评价**既看预测误差，也看实际费用、紧急购电与约束是否满足。

预测精度提高不一定带来更低电费；少预测一个高负荷峰值可能比很多低负荷时段的小误差更昂贵。

## 2. 第一问：确定性储能调度

**直接使用附件 1 的单日电价、负载和光伏预测，不重新训练预测器。**

决策变量为各十分钟区间的正常购电量、充电量、放电量和电池储电量。目标为最小化全天购电费用：

\[
\min \sum_t p_t g_t.
\]

约束包括负载供电、能量守恒、电池容量、充放电功率、效率、充放电互斥，以及日末储电量等于日初。共同物理公式见 [数据约定](DATA_CONTRACT.md)。

主实现建议 MILP：用一个二元状态区分充电与放电。可以先用 LP 调试，但不能把出现同时充放电的松弛结果直接作为物理调度结果。

对照：无储能的按缺口购电策略。展示总费用、每十分钟购电量、SOC 轨迹、充放电时段及指定汇总。检查节省是否来自合理移峰，而不是耗空电池或效率算错。

## 3. 第二问：预测误差下的日前购电

### 题目是什么意思

每天 00:00 先确定当天购电计划。实际负载或光伏与预期不同，电池调节后仍有缺口时，需要按正常交易电价的五倍紧急购电。普通购电按**计划量**付费，即使最终没有全部使用。

因此应最小化：

\[
C_2=\sum_t p_t g_t^{plan}+\sum_t5p_t e_t.
\]

“外网”指外部电网。题面重点不是固定订阅费用，而是计划购电及紧急补电的费用。

### 是否应追求零紧急购电

可以设计保守方案，例如增加计划余量、保留电池储备、针对有界误差做鲁棒约束。但零紧急购电不必然最省钱。

**仅用于解释的例子，非附件结果：**某区间正常电价 1 元/kWh，不考虑电池，需求有 99% 概率是 100 kWh、1% 概率是 110 kWh。计划买 100 kWh 时，期望费用为 100＋1%×10×5＝100.5 元；计划买 110 kWh 可在这两个情景下消除紧急购电，但费用为 110 元。

“历史回测未触发紧急购电”不等于保证任何未来情况下都不触发。要宣称保证，必须写清不确定性范围和供电能力。若想完全不从外网买电，则还需逐时验证光伏与储能是否足够；电池只是转移电能，不能凭空发电。

### 推荐路线

1. 建立最近一天／一周同一时段的同期预测基线。
2. 将岭回归作为负载预测候选，用历史滞后、已发生的滚动统计、目标时段和星期等特征；正则强度只在时间验证集上选择。
3. 光伏使用历史同一时段曲线、近期水平校正和岭回归候选；明确夜间为零、白天预测非负。没有未来气象预报时，不虚构气象输入，也不把第三问的新增预报提前当作第二问已知信息。
4. 在过去预测误差上校准净负载风险余量。先用易解释的余量方案，必要时扩展为误差场景或分位数方法。
5. 把预测曲线与余量送入第一问扩展的调度器，得到不可事后更改的日前购电计划。
6. 逐时根据可获得的信息执行电池控制，剩余缺口以紧急购电补齐，并累积真实费用。

注意：净负载为负载减光伏；两个预测误差可能相关。不要随意独立打乱样本生成不真实场景。场景优化的日前决策必须一致，后续控制必须满足信息可见性，不能利用整天实际路径事后选择电池动作。

实验比较不留余量、保守余量、验证集选择的余量；以总费用为主要结果，同时展示紧急购电、富余计划电量和供电可行性。岭回归不是已确定的最优预测器，应保留同期基线以检验它是否有收益。

## 4. 第三问：带调整费用的日内滚动优化

**用户的理解成立：核心是判断新预报的收益是否足够覆盖调整代价。** 推荐模型为 MPC，不要求训练神经网络。

附件 3 在每天 00:00、06:00、12:00、18:00 发布未来 24 小时的光伏预报。负载仍需要预测；附件只给了光伏新预报，不能把未来负载一起当作已知。

步骤：

1. 00:00 利用此刻预报制定原始计划。
2. 每次日内预报发布时，读取最新预报、过去观测和当前真实 SOC。
3. 对尚未执行区间重新优化，同时计算减购违约费用、增购费用和可能避免的紧急费用。
4. 已执行区间冻结；保存新旧计划及调整明细，实际运行仍按十分钟推进。
5. 保留“不调整”的可行选择，而不是要求每次有预报都改计划。

题面规定减购部分违约电价为原电价 50%，增购部分为 1.5 倍，紧急购电为 5 倍。退不退原款、多次调整以哪一版为基准必须统一，详见 [数据约定](DATA_CONTRACT.md)。

实验至少比较：仅午夜预报、增加一次更新、使用全部更新；时间允许时比较 06/12/18 三个更新时间的 8 个子集。各组均使用其决策时已发布的预报，不能给“仅午夜组”提前使用日内新版。

同一决策问题中，更多信息且允许不采取行动不会减少可选策略；但有限样本和预测误差下，实际回测成本不保证单调降低。应报告结果而非预设结论。

## 5. 第四问：波动电价＋GRU 对照实验

### 附件确实有价格数据

附件 4 包含 365 天、每天 144 个十分钟价格，共 52,560 个价格点，单位为元/kWh。它可以用于历史训练与后续评价。

但附件给出全年实际值，不自动代表当天 00:00 已公布当天所有未来电价。推荐主方案把未来价格视为未知并预测；若采用价格已知解释，必须作为另一项信息假设说明。

### 两套方案怎么设计

用户希望试神经网络，保留以下研究路线：

| 方案 | 价格预测器 | 调度框架 |
| --- | --- | --- |
| 简单基线 | 日／周同期预测 | 第二问日前策略、第三问滚动策略分别运行 |
| 非神经网络主对照 | 岭回归；有余力再比较树模型 | 与 GRU 使用同一调度器及参数 |
| 神经网络试验 | 小型 GRU，LSTM 为可选补充 | 与非神经网络使用同一调度器及参数 |

至少形成“2 种候选预测器 × 2 类调度策略”的比较；题目需要 result4-2 和 result4-3 两份结果，不能只训练电价模型而漏掉其中一类策略。

初期保持负载、光伏预测及风险余量一致，只改变电价预测器，以便识别价格预测的贡献。若再分别针对各预测器调参，应另外标记为端到端策略比较，并给予相同验证和调参预算。

评价分两层：价格 MAE/RMSE、尖峰时段误差；以及真实总费用、紧急费用、调整费用、弃电／富余电量和可行性。最终模型由验证与回测证据决定，不能只展示 GRU 拟合训练集的曲线。

这种方法对照是合理的建模研究设计。论文应解释为什么比较、如何公平验证以及何时有效；算法名称多、神经网络复杂本身不能替代问题分析。可以另列提前知道价格的理想信息参照，但它不能与真实预测器混为同等信息条件的对手，也不自动构成所有成本口径下的严格理论下界。

## 6. 共同交付与实施次序

先统一约定并完成第一问，再跑第二问基线、第三问滚动，最后接第四问 GRU 对照。每层复用经过核验的能量平衡、费用账本与导出模块。

最终应有五份结果工作簿、指定日期汇总、统一图表、假设及敏感性分析、可复现代码与实验记录。**这些是后续交付目标，本次仅提交研究方案。**
